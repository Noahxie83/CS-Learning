## 1.3.2 大O记号
即$T(n)=O(f(n))$  
$iff$ $∃c>0$,当$n>>2$后,有$T(n)<c·f(n)$
	与$T(n)$相比，$f(n$)更为简洁，但依然反映前者的增长趋势
		常系数可忽略：$O(f(n))=O(c·f(n))$  
		低次项可忽略:$O(n^a+n^b)=O(n^a),a>b>0$  
![[Pasted image 20260823015840.png]]
![[Pasted image 20260823020033.png]]
## 1.3.3 高效解
常数复杂度：$O(1)$
	这类算法的效率最高
	通常是不含转向(循环、调用、递归等)必顺序执行，即是$O(1)$
对数复杂度：$O(logn)$
	常底数无所谓
	常数次幂无所谓
	对数多项式
	这类算法非常有效，复杂度无限趋近于常数
## 1.3.4 有效解
多项式复杂度：$O(n^c)$
	线性：所有$O(n)$类函数
## 1.3.5 难解
指数复杂度：$O(a^n)$
	这类算法计算成本增长极快，通常被认为不可忍受
	从$O(n^c)$到$O(a^n)$，是从**有效算法**到**无效算法**的分水岭

# 1.4 复杂度分析
## 1.4.1 算法分析
原则：去粗存精式的估算
两个主要任务=正确性(不变形×单调性)+复杂度
C++等高级语言的基本指令，均等效于常数条RAM的基本指令；在渐进意义下，二者大体相当
	分支转向：**goto**
	迭代循环：for()、while()、……//本质上if + goto
	调用+递归(自我调用)
复杂度分析的主要方法
	迭代：级数求和
	递归：递归跟踪+递推方程
	猜测+验证
## 1.4.2 级数
**算数**级数：与**末项平方**同阶
如：$T(n)=1+2+3+……+n=\frac{n(n+1)}{2}=O(n^2)$
**幂方**级数：比幂次高处**一阶**
$\sum_{k=0}^{n}k^d≈\int_0^{n}x^{d+1}dx=\frac{1}{d+1}n^{d+1}=O(n^{d+1})$
**几何**级数$(a>1)$：与**末项**同阶
**收敛**级数：$O(1)$
	注意一些未必收敛，长度有限的级数
		调和级数：$\sum_{i=1}^{n}\frac{1}{i}=\phi(logn)$
		对数级数：$\sum_{i=1}^{n}logi=log(n!)=\phi(nlogn)$
## 1.4.3 循环
例1(注意内层循环次数)

# 1.5 迭代与递归
## 1.5.1 迭代与递归
	分而治之思想：将规模大的问题分解为几个相对更小的部分或者是子问题递归式地求解
### 实例：数组求和
**问题：计算任意n个整数之和**
算法实现：
```
	int SumI(int A[],int n){
		int sum=0;//O(1)
		for (int i=0;i<n;i++){//O(1)
			sum+=A[i];//O(1)
			}
		return sum;//O(1)
```
无论A[]内容如何，都有
	时间复杂度=1+n×1+1=O(n)
	空间复杂度=O(2)
		考量处理输入本身所占的空间之外，需要另加的用于计算所必须的空间总量

## \*1.5.8 Max2：
	从数组区间A[low,high)中找出最大的两个整数A[x1]和A[x2]
	元素比较的次数要求尽可能地少
### 迭代1
![[Pasted image 20260823215054.png|405]]
```
void max2(int A[],int low,int high,int &x1,int &x2){
	for (int i=low+1,x1=low;i<high;i++)
        if (A[x1]<A[i]) x1=i;
    for (int i=low+1,x2=low;i<x1;i++)
        if (A[x2]<A[i]) x2=i;
    for (int i=x1+1;i<high;i++)
        if (A[x2]<A[i]) x2=i;
}
```

```
void max2(int A[],int low,int high,int &x1,int &x2) {
	if (low+2==high) { /* ... */; return; }
	if (low+3==high) { /* ... */; return; }
	int mid=(low+high)/2; //divide
	int x1L,x2L;max2(A,low,mid,x1L,x2L);

}
```

## 1.6.9 LCS：复杂度
单调性：无论如何，每经过一次比对，原问题的规模必可减小
具体地，作为输入的两个序列，至少其一的长度缩短一个单位
最好情况下，只需$O(n+m)$时间
但在第二种情况下原问题将分解为两个子问题，它们在随后进一步导出的子问题，可能雷同
在最坏情况下，LCS(A\[0,a],B\[0,B])出现的次数为
$$
(^{n+m-a-b}_{n-a})=(^{n+m-a-b}_{m-a})
$$
特别地，LCS(A\[0],B\[0])的次数可多达
$$
(^{n+m}_{n})=(^{n+m}_{m})
$$
当n=m时，为$O(2^n)$

## 1.7.6 连续访问
当频繁访问某个数据时，机器会预测并提前将附近的数据加载到高速缓存中，以减少访问延迟，提高效率。这种机制在处理大量数据时尤为重要，能够显著提升访问速度。
访问有规律性而非随机性，这种规律性能够减少I/O操作的频率，从而减轻系统负担并加速数据处理。因此不仅需要正确实现逻辑，还应注意数据访问的规律性，以利用操作系统缓存机制的优势。
